# Changelog

## 0.2.0 — 2026-10-14

- Add Antigravity CLI eligibility signatures for x64 and ARM64.
- Move from the Windows-only PowerShell prototype to a shared Python engine.
- Support PE, ELF and Mach-O code-section recognition.
- Add native Windows, Linux and macOS release workflows.
- Use an English interface and a Russian Markdown README.
- Keep verified backups outside application folders; prevent restore over updates.
- Add macOS signing snapshots and transactional ad-hoc signing.
- Read verified backups from the earlier Windows PowerShell prototype.
- Add transaction tests and an isolated packaged-runtime self-test.
- Treat an already published release as a successful no-op; keep its assets unchanged.

## 0.1.0

- Windows PowerShell prototype for IDE and Manager x64; no CLI support.
